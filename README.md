# JustUninstallApps
🗑️ Lightweight, free &amp; open-source app uninstaller for Windows — fast, clean, and zero bloatware. By iJUST-Apps
📖 About
JustUninstallApps is a free, open-source Windows utility built by IJUST-Apps.
Most modern "PC cleaners" and uninstallers are overloaded with background services, intrusive ads, popups, and heavy resource usage. JustUninstallApps takes the opposite approach: it launches fast, stays out of your way, and gives you only the tools you actually need to remove unwanted programs and keep your system tidy.
🚫 No Bloatware
🚫 No Background Services or Telemetry
🚫 No Ads or Subscriptions

✨ Features
⚡ Simple, Clean & Efficient: Lightweight interface designed for speed and ease of use without unnecessary clutter.
🧹 Complete Uninstall: Remove installed applications cleanly and thoroughly without leaving broken entries behind.
🗑️ One-Click Junk Cleaner: Dedicated Clean Junk button to clear out leftover temporary files and residual clutter quickly.
🎨 Custom Themes (Work in Progress): UI theme customization is currently under active development and scheduled to arrive in the next update.

🚀 Getting Started
Option 1: Download Ready-to-Run .exe (Recommended)
Go to the Releases page.
Download the latest JustUninstallApps.exe (or .zip archive).
Run the executable directly — no installation required.
Option 2: Run from Python Source
Clone the repository:
git clone https://github.com/IJUST-Apps/JustUninstallApps.git
cd JustUninstallApps
Install dependencies (if applicable) and run:
python main.py
(Update main.py above to match your main script filename.)
