# JustUninstallApps

> Lightweight, free & open-source app uninstaller for Windows — fast, clean, and zero bloatware. By **IJUST-Apps**.

## About

JustUninstallApps is a free, open-source Windows utility built by **IJUST-Apps**.

Most modern "PC cleaners" and uninstallers are overloaded with background services, intrusive ads, popups, and heavy resource usage. JustUninstallApps takes the opposite approach: it launches fast, stays out of your way, and gives you only the tools you actually need to remove unwanted programs and keep your system tidy.

- **No Bloatware**
- **No Background Services or Telemetry**
- **No Ads or Subscriptions**

## Features

- **Simple, Clean & Efficient:** Lightweight interface designed for speed and ease of use without unnecessary clutter.
- **Complete Uninstall:** Remove installed applications cleanly and thoroughly without leaving broken entries behind.
- **One-Click Junk Cleaner:** Dedicated **Clean Junk** button to clear out leftover temporary files and residual clutter quickly.
- **Custom Themes (In Progress):** UI theme customization may be added in a future update.

## Getting Started

### Option 1: Download Portable Release (Recommended)

1. Go to the **Releases** page.
2. Download the latest `JustUninstallApps-v1.0.0.zip` archive.
3. Extract the files (`JustUninstallApps.exe` and `app.ico`) and run `JustUninstallApps.exe` directly — no installation required.

### Option 2: Run from Python Source

Clone the repository and run the script (update `JustUninstallApps.py` if your main script has a different filename):

```bash
git clone [https://github.com/IJUST-Apps/JustUninstallApps.git](https://github.com/IJUST-Apps/JustUninstallApps.git)
cd JustUninstallApps
python JustUninstallApps.py
```
